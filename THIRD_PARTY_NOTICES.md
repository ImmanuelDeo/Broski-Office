# Referensi pihak ketiga

Kode dan mesh original dalam paket memakai lisensi MIT (LICENSE). Tidak ada kode Three.js, model komersial, font bundel pihak ketiga atau source ai-creative-team yang disalin dalam ZIP.

ai-creative-team oleh bekhruztbx adalah referensi desain alur; README menyebut lisensi MIT dan lisensi SIL OFL untuk font Geist dalam tools/fonts. Script fetch_upstream mengambil checkout asli ketika pengguna melakukan setup; pertahankan lisensi yang disertakan checkout tersebut dan catat commit aktual.

Hermes Agent adalah dependensi eksternal milik NousResearch. Paket tidak menyertakan Hermes, provider API key atau bobot LLM; instalasi dan penggunaan mengikuti lisensi serta ketentuan dependensi yang dipilih pengguna. Nama dan merek pihak ketiga digunakan untuk menjelaskan integrasi, bukan menyatakan afiliasi.
