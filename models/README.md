# Aset 3D Nexus

Model prosedural original: big-brain.obj, agent-base.obj, room-base.obj. Lisensi MIT seperti kode proyek. Dibuat dari Geometry di web/scene.js lewat scripts/export_models.mjs. Ini mesh polygonal, bukan gambar atau bobot AI. Buka/import di Blender jika ingin mengedit. Runtime kantor membuat ulang bentuk secara prosedural; OBJ adalah aset pendamping yang tidak dimuat otomatis oleh UI.
