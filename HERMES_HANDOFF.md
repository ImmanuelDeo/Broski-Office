# Instruksi serah-terima untuk Hermes lokal

Saya ingin kamu memasang proyek Nexus Office dari folder ini, memverifikasi integrasinya dengan instalasi Hermes milik saya, lalu menjalankannya di localhost. Baca semua panduan sebelum mengubah konfigurasi. Jangan mengubah source memory, memasukkan rahasia ke repository, memublikasikan hasil, menonaktifkan approval tool, atau memakai profil Hermes pribadi saya untuk worker paralel.

1. Baca START_HERE.md, docs/HERMES_SETUP.md, docs/ARCHITECTURE.md, dan docs/REFERENCE_AND_LIMITS.md.
2. Temukan OS, Python, lokasi Hermes, `hermes --version`, `hermes chat --help`, `hermes profile list`. Jangan mengasumsikan versi atau flag. Jalankan `python scripts/doctor.py`.
3. Jalankan `python -m unittest discover -s tests -v`, lalu jalankan kantor dalam mode demo. Buka http://127.0.0.1:8765 dan verifikasi Big Brain, seluruh tim, kamera, tugas paralel, reviewer, serta persetujuan pengguna.
4. Identifikasi cached memory saya dari konfigurasi Hermes, bukan dari nama file tebakan. Masukkan hanya path file pengetahuan yang dipilih pada memory_sources. MEMORY.md/USER.md default hanya titik awal. Jangan masukkan .env, auth.json, token, atau database kredensial. Untuk provider eksternal/KV cache, jelaskan kebutuhan adapter; jangan menyatakan telah mengimpor jika belum.
5. Backup konfigurasi yang akan diubah. Buat atau gunakan ulang profil `office-*` yang tercantum pada config/office.json. Setiap agen harus memiliki profil sendiri, khusus kantor ini, tanpa cron, channel, atau pekerjaan lain. Provider/model mengikuti akun yang sudah saya konfigurasi. Kolom model kosong berarti menggunakan default profil; jangan memilih model berbayar lain secara diam-diam.
6. Periksa apakah CLI bersifat in-process atau gateway-backed. Untuk gateway-backed, gunakan profil kantor standalone dengan `gateway.standalone: true` bila versi ini mendukungnya. Jangan menghentikan gateway default atau memakai `--all`. Pastikan `hermes --profile <office-profile> gateway stop` hanya menghentikan profil kantor yang dimaksud. Jika semantik versi berbeda, sesuaikan hermes_command/hermes_chat_args/hermes_stop_args dan buktikan perilakunya sebelum live_ready=true.
7. Pasang MCP nexus_office dari docs/HERMES_SETUP.md pada setiap profil, memakai path absolut Python, mcp_server.py dan .runtime. Pertahankan server MCP yang sudah ada. Jangan menimpa config.yaml utuh. Konfigurasi gateway harus memiliki NEXUS_URL dan NEXUS_DATA_DIR yang stabil; task_id dilaporkan sebagai argumen tool dari prompt, bukan mengandalkan environment sesi gateway.
8. Jalankan `python scripts/fetch_upstream.py` jika Creative Studio akan mengolah video. Baca README, LICENSE, CLAUDE.md, agent prompts, command edit-clips, dan tools/setup.sh pada checkout asli. Catat commit pada external/upstream-lock.json. Instal ffmpeg dan dependensi tools sesuai upstream. Jangan menyatakan media siap hanya karena cloning berhasil. Daftarkan path checkout dan aturan brand sebagai proposal Big Brain, lalu minta pengguna meninjau proposal konkret itu.
9. Konfigurasikan izin tool Hermes sesuai kemampuan masing-masing peran. Prompt kantor bukan sandbox. Tidak perlu mode yolo. Test akses baca sumber serta tulis folder output. Jangan memberi akses publik pada server kantor.
10. Siapkan satu smoke test live yang aman dan kecil: buat teks lokal, laporkan office_progress dengan task_id, baca office_brain, tulis result.json sesuai instruksi prompt, lalu reviewer membaca hasil. Aktifkan mode live dan live_ready hanya setelah prasyarat konfigurasi terpenuhi; uji satu run terlebih dahulu. Jika gagal, kembali ke demo dan jelaskan error asli. Jangan menganggap exit code 0 sebagai bukti hasil ada.
11. Uji cancel dan timeout pada tugas uji: pastikan proses agen/gateway profil terkait benar-benar berhenti. Bila NEEDS_RECONCILIATION muncul, inspeksi profil dan output, hentikan pekerjaan tersisa secara terarah, lalu jalankan scripts/reconcile.py --confirmed-stopped. Jangan menghapus hold tanpa pemeriksaan.
12. Pastikan sumber memori tidak berubah oleh importer, ukuran byte cocok, dua worker tidak berbagi profil, dan reviewer tidak dimulai sebelum semua worker selesai. Periksa hasil nyata dan artefak di .runtime/runs/.
13. Laporkan URL lokal, versi Python/Hermes, profil dan model yang benar-benar dipakai, lokasi output, tes yang lolos, dan batas yang masih ada. Jangan mencantumkan kredensial.

Jika dibutuhkan penyesuaian desain agar mendekati video, gunakan frame video yang saya berikan. Jangan mengklaim persentase kemiripan tanpa perbandingan. Model 3D prosedural dan OBJ berada dalam paket; tidak perlu mengunduh aset berbayar.
